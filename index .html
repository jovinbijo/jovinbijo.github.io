Project 01 · Personal project

3D Gaussian Splatting for Real-Time Rendering

The problem

Turning ordinary photographs of a scene into a 3D representation that can be explored from new viewpoints in real time.

Approach

  • Set up and trained a 3D Gaussian Splatting pipeline for radiance-field rendering using PyTorch and CUDA.
  • Prepared custom image datasets with COLMAP (Structure-from-Motion) for training.
  • Explored the trained models in an SIBR-based real-time viewer and evaluated the novel-view output.
  • Worked through GPU-accelerated training and implemented techniques from research papers.

Stack

PyTorchCUDACOLMAPSIBR viewerPython

Project 02 · Major project

EcoRoute Optimizer

The problem

Courier and logistics services need routes that are efficient on fuel, with delivery times they can predict, plus live visibility of couriers.

Approach

  • Python and Flask back-end with MySQL, using OpenStreetMap and the TomTom API for map data.
  • XGBoost model for ETA prediction, reaching about 94% accuracy.
  • Fuel-efficient route ranking algorithm, reaching about 90% accuracy.
  • Real-time courier tracking from live location data through mapping APIs.

Stack

PythonFlaskMySQLXGBoostOpenStreetMapTomTom API

My contribution

Built the ETA prediction model, the route ranking algorithm and the courier tracking feature.
